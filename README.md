# Non-circular Halbach Array Design using Conformal Mapping
This software illustrates how conformal mapping can be used to design Halbach magnet arrays on various shapes.

## Requirements
- Python 3.x
- install the packages listed in `requirements.txt`

## Running the code
Run `non-circular_Halbach.py` from the command line (e.g., `> python non-circular_Halbach.py`) or inside an IDE like [Spyder](https://www.spyder-ide.org/).
